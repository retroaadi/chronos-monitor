
# Chronos Monitor
### Phase 2 — Completed Implementation

Chronos Monitor is a C++ console-based academic project developed by **Team ByteCare**. It demonstrates telemetry generation, telemetry data handling, and alert management using Object-Oriented Programming (OOP) and Data Structures.

This README describes the work completed in Phase 2 and provides representative console outputs.

## 1. Completed Work

### Module 1 — Telemetry Record and Generation

Implemented the telemetry foundation used by the monitoring system.

- Created a telemetry record representation.
- Implemented a telemetry generator for simulated monitoring data.
- Added a test program for record creation and telemetry generation.
- Established a record format for downstream processing.

**Status:** Implemented and tested as an individual module. Telemetry is simulated; live operating-system data collection is not included in the completed work described here.

### Module 2 — Telemetry Data Storage

Implemented the data-storage component used to manage telemetry records.

- Developed the storage component as a separate module.
- Prepared the module to work with telemetry records generated by Module 1.
- Organized the storage implementation for testing and integration.

**Status:** Implemented as a project module. Specific data structures and operations should be documented according to the current source code.

### Module 3 — Alert Management

Implemented the alert-management component for handling alert records.

- Created the `Alert` class.
- Created the `Alert_Manager` class.
- Added a test program for alert-management behavior.
- Organized alert processing into a separate module.

**Status:** Implemented and tested as an individual module. Exact thresholds, severity rules, and output depend on the current implementation.
